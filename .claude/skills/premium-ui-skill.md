# 高级界面 UI Skill（Premium UI Skill）

## 设计原则
- 极简但大胆（Minimal but bold）
- 强层级排版（Typography hierarchy）
- 大间距 / 留白布局（Breathing layout）
- 避免卡片堆叠（Avoid card overuse）
- 避免廉价渐变（Avoid cheap gradients）

## 视觉系统
- 8px 间距网格（8px spacing grid）
- 柔和阴影系统（Soft shadow system）
- 仅用一个主色（1 primary color only）
- 中性色背景（Neutral background）

## 风格参考
- Apple + Stripe + Linear 风格
- 高端 SaaS 风格（Premium SaaS look）

## 使用流程
1. 先定义设计风格（Style first）
2. 再布局（Layout）
3. 然后生成组件（Components）
4. 最后优化视觉细节（Refine visuals）
