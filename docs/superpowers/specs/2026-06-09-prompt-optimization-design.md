# 文案生成提示词优化设计方案

## 概述

优化爆火视频文案生产器的 AI 提示词，使生成的短视频脚本在开场钩子、情绪共鸣、标题点击欲、真人语感等方面全方位提升吸引力，同时保持代码结构不变。

## 目标

- 提高生成文案的完播率驱动能力（前 3 秒留存）
- 增强情绪共鸣和互动率（评论/点赞/收藏）
- 消除 AI 味，更接近真人博主语感
- 区分抖音和小红书平台调性
- 降低输出格式解析失败率

## 改动范围

| 文件 | 改动内容 |
|------|---------|
| `src/prompts/index.js` | 重写 SYSTEM_PROMPT，优化 buildUserPrompt，重写 buildEnhancePrompt |
| `src/services/ai.js` | 让 temperature 可配置（默认保持兼容） |

## 设计细节

### 一、System Prompt 重写

#### 新增：5 大传播驱动力

每个输出必须满足的好奇心缺口、情绪共振、社交货币、互动诱因、高完播率，作为 AI 自我评估的框架。

#### 新增：6 个钩子公式

每个钩子配备具体话术模板和示例：
1. 痛点代入 — "你是不是也觉得 + 具体痛点"
2. 数字冲击 — "我试了 XX 次，只有这 X 个方法有用"
3. 反常识 — "关于 XX，99% 的人都搞反了一件事"
4. 悬念留白 — "我花了 3 年才明白的一个道理"
5. 场景切片 — "凌晨 2 点，手机屏幕还亮着"
6. 立场宣言 — "有些话我忍了很久，今天必须说出来"

#### 新增：平台差异化规则

- 抖音：节奏更快、开场更炸、结尾扣1/评论区见
- 小红书：语气温暖像朋友推荐、强调收藏价值、"亲测""说实话"

#### 优化：8 条铁律（原 6 条）

移除原第 4 条（禁止套话列表简化），新增"具体代替抽象"（配正反例）、"每个分镜有情绪"、更详细的 AI 套话黑名单

#### 保留：输出结构、分镜数量、参考链接处理

### 二、User Prompt 优化

#### 新增：预思考引导

要求 AI 在生成前先分析目标观众和切入点，提升输出深度。

#### 新增：平台风格提示

根据选择平台注入不同的语气和节奏指引。

#### 优化：JSON 格式引导

更清晰的 JSON 结构说明，减少解析失败。

### 三、Enhance Prompt 重写

#### 润色模式
- 逐句替换 AI 感表达为地道说法
- 增加"你懂吧？""说实话""真的"等口语词
- 减少被动语态和书面结构

#### 压缩模式
- 每句旁白削减 30% 字数
- 删除铺垫性废话，保留情绪核心
- 关键结论改为 3-8 字短句

#### 强化互动模式
- 不只是最后一句，每段埋互动点
- 增加观点对立/站队引导
- 设计评论区话题方向

### 四、Temperature 可配置化

- `callAIStream` 函数增加可选 `temperature` 参数
- 首次生成使用 0.85（更高创意）
- 润色/压缩/增强使用 0.7（保持结构稳定）
- 默认值 0.8 保持向后兼容

- `templates/index.js` — 不改
- 所有组件文件 — 不改
