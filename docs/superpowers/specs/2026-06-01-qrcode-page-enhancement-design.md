# 二维码生成页面优化设计

## 概述

为现有二维码生成页面增加外观定制（颜色、纠错等级、尺寸）、历史记录、复制图片等实用功能，提升页面丰富度和易用性。

## 设计布局

采用方案 B：可折叠选项面板。自上而下：

```
输入区（输入框 + 清空按钮 + 生成按钮）
二维码展示区
自定义选项面板（前景色/背景色/纠错等级/尺寸）
操作按钮栏（下载 PNG / 复制图片）
内容预览
最近记录列表（点击恢复 + 清空）
```

## 功能详情

### 1. 输入区
- 现有输入框右侧增加 × 清空按钮，清空输入和二维码
- 回车 / 点击「生成二维码」触发生成

### 2. 二维码展示
- 现有 Canvas 渲染，保留白色背景区域

### 3. 自定义选项面板（新增）
- 独立浅色背景面板，置于二维码下方
- **颜色**：两个 `<input type="color">`，默认前景 `#1a1a1a`、背景 `#ffffff`
- **纠错等级**：分段按钮 L(7%) / M(15%) / Q(25%) / H(30%)，默认 M
- **尺寸**：分段按钮 小(180px) / 中(240px) / 大(320px)，默认 中(240px)
- 任一选项变化自动重新生成二维码（调用 `regenerate` 方法）

### 4. 操作按钮栏（新增）
- 「下载 PNG」— 现有 `canvas.toDataURL + 创建 a 标签下载`
- 「复制图片」— 使用 `navigator.clipboard.write([new ClipboardItem({ 'image/png': blob })])`，浏览器不支持时降级为复制文本

### 5. 最近记录（新增）
- localStorage 存储，key `qrcode-history-list`
- 每次生成自动记录，去重（同内容移到最前），最多 8 条
- 格式：`{ id, text, time }`
- 点击任一条恢复文本并重新生成
- 底部「清空」按钮删除所有记录
- 页面加载时自动恢复历史列表

## 技术要点

- 全部改动用 `qrcode` 库已有能力实现，无需新增依赖
- `errorCorrectionLevel` 是 `QRCode.toCanvas` 原生支持的选项
- 颜色改动通过 `color.dark` / `color.light` 控制
- 历史记录使用 localStorage，错误时静默降级为空列表

## 不变部分

- 页面暗色卡片风格不变
- 页头标题 / 描述不变
- 单个页面内单列布局不变
- 无路由变化，无新页面

## 影响范围

仅修改 `src/pages/qrcode-generator/index.vue` 一个文件。
